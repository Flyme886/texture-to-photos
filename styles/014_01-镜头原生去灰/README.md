# 镜头原生去灰

**A · 稳妥**　改动强度：轻　·　原分类：光影塑形与原片增强

去灰去雾、色彩纯度与分离提升，蓝天更净、黄叶更浓，明暗层次清楚但不改原有光影氛围，像旗舰相机直出

| 适合题材 | 适合光线 | 不适合 |
|---|---|---|
| 风光、街景、城市建筑、植物花卉、人像、交通工具 | 晴天顺光、阴天、任意 | 想要明显风格化调色的用户 |

## 提示词

```text
模拟顶级全画幅相机与高品质光学镜头的原生色彩表现，采用专业数字暗房精修理念，在保持照片原始风格的前提下，全面提升视觉品质。 
光学表现： 优化画面清澈度、光线纯净度与自然透视层次，减少不必要的灰白感及杂散眩光，呈现干净透明、柔和细腻的高级镜头质感。 
色彩表现： 增强色彩纯度、自然浓度及层次分离，优化不同颜色之间的协调关系，使色彩鲜活、饱满、真实且富有质感，避免艳俗和人工色偏。 
明暗表现： 精细调整亮度过渡与局部明暗关系，使高光柔和通透、中间调饱满立体、阴影自然深邃，增强画面层次而不改变原有光影氛围。 
质感表现： 优化细节微反差、材质纹理与边缘过渡，呈现精致、细腻、自然锐利的光学成像效果，避免过度锐化和数字加工痕迹。 
视觉优化： 自适应协调色彩、亮度、层次与视觉重心，提升画面的整体和谐度、舒适度与高级感。 
严格保留原始构图、人物外貌、画面内容、真实肤色、景深、白平衡及环境氛围。 不改变摄影风格，不制造虚假细节，不使用夸张HDR。 
最终呈现如顶级专业相机精心拍摄的自然直出质感，真实、纯净、通透、细腻且耐看。
```
