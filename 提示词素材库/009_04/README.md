# 黑夜电青

分类：风格重构与特殊题材。共2组。

[提示词原文](提示词.txt)

```text
严格保持原视频人物、面部、服装款式、车辆型号、建筑结构、道路、地形、场景布局、构图、透视及全部动作不变。
对原视频进行强烈电影级黑青双色风格转换（Deep Black & Electric Cyan Color Grading），执行全画面选择性色相重映射，而非仅改变灯光颜色。
将除人物肤色、原有白色及黑色材质以外的蓝、绿、黄、橙、红、紫等彩色材质，强烈转换为高饱和电光青绿、亮青色或深青色，包括车辆、服装、建筑、植被、标识及各种彩色物体。亮部呈现鲜艳电光青绿，暗部转为深青黑色，完全无光区域保持纯黑，不得无故发光。
原有白色材质严格保持干净纯正的中性白色，不得染青、染蓝或变灰，保留真实纹理及自然明暗层次，暗部允许自然压暗，不强制提亮。原有黑色材质保持深邃纯黑。人物所有裸露皮肤保持自然真实暖肤色，不参与青绿色重映射。
整体采用极高反差暗黑电影摄影风格，大幅压低黑位与中间调，突出局部高饱和青绿色高光。白天场景转换为深黑夜景，夜晚场景保留原有结构。
地面保持原始干燥、粗糙、低反射质感，禁止积水、湿地、镜面倒影及大面积青色反光。
严格保留物体形状、材质纹理、镜头运动及景深。禁止灰蒙蒙、低饱和、均匀青色滤镜、过度HDR、无来源泛光及改变原始主体。
最终呈现极深纯黑、高饱和电光青绿、干净纯白、自然暖肤色相互分离的电影级暗黑霓虹视觉效果。
```
