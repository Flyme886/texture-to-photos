# 夜色下的低调的青橙色调，复古克制不浓郁

分类：青橙冷暖电影色。共3组。

[提示词原文](提示词.txt)

```text

以原始照片为基础进行电影化重塑，严格保留人物数量、外貌特征、姿态、物体位置、构图、透视、场景结构及原有光源，不新增或改变场景元素。营造静谧、孤独、怀旧、忧郁且富有诗意的电影氛围。
**色彩表现：**以深翡翠绿、墨绿、灰青绿统领环境，暗部呈纯净深邃的绿黑色，中间调浓郁厚重，受光区域呈现通透柔和的青绿色。原有暖光转化为琥珀橙、钨丝金黄与褪色橘红。冷暖色自然交融，暗部适度收敛饱和度，避免生硬青橙对比、脏黄褐色及全局滤镜感。
**光影层次：**采用低调曝光与浓密阴影，允许局部自然沉入纯黑。保持深邃黑位、柔和中间调与平滑高光滚降，明暗过渡细腻连续，避免强行提亮暗部。突出原有光源的自然Bloom、轻微Halation与局部Soft Diffusion，使亮部柔和溢出，光色在空气中自然扩散，形成通透而克制的空间朦胧感。
**画面质感：**呈现高品质电影摄影的纯净、细腻与柔软质感。保持人物和物体结构清晰完整，降低数字锐化与生硬微对比，柔化光线而非模糊画面。暗部均匀纯净，色彩渐变平滑，材质自然，不刻意增加纹理。
**严格禁止：**明显胶片颗粒、暗部噪点、粗糙斑驳、砂纸质感、污渍、色块结团、色彩断层、脏灰雾、全局泛光、过度柔焦、HDR、新增光源及人为做旧。
最终呈现：深绿而不浑浊，浓郁而不艳俗，暗而不脏，柔而不糊，光影通透，具有时间停滞感的电影剧照质感。
```
