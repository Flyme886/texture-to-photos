# 侘寂深灰 | 提示词

分类：暗调冷色与雾感。共3组。

[提示词原文](提示词.txt)

```text
“按原有构图，仅作色调更改，侘寂极简风格，低曝光深黑灰基底色调，主体和环境不发黄，相似覆盖了一层透明度为％50黑色图层。全局色彩规则：除去黑白灰基础色，所有色彩统一控制为中等饱和度；暖色系（红色、橙色、橙黄、黄色、木色、土黄、棕色）饱和度与明亮度显著高于冷色系，作为画面视觉重点；剩余冷色、杂色统一处理成低饱和。阴影与暗部为深沉近黑深灰色，绝非死黑，勉强保留物体纹理、轮廓层次；暗部底色和地面、水面偏向沥青深黑灰色；影调分层：暗部冷沉深灰，中间调过渡为沥青冷灰，亮部柔和延展。高光严格约束，杜绝过曝，仅奶白、浅陶色柔和点缀，依靠大面积暗调衬托少量暖色主体。对比度控制：暗部至中间调对比强烈、层次压沉利落；中间调向高光过强硬直接，硬光，原生小光比。暗部信息压低至极限。适度强化画面锐度，整体带有通透自然的高对比实拍，无颗粒纯净质感。”
```
