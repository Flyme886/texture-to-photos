# 聚光流雾

分类：风格重构与特殊题材。共1组。

```text
以原图为唯一基础，严格保留人物姿态、服装、头盔、摩托车造型、车漆颜色及构图，打造黑色无缝摄影棚中的高级电影级低调光影。背景深邃纯黑，顶部大型柔光源投射集中而自然的冷白光，塑造头盔、肩部及车身细腻的明暗体积，保留金属反射与深黑材质层次。
重点重构地面照明，顶部斜向聚光光线自然延伸至地面，在人物与摩托车周围形成宽阔柔和的椭圆形冷灰色光区，亮度由中心向四周平滑衰减。车轮与地面形成厚重真实的接触阴影及柔和投影，地面纯黑哑光，无反射、有明显沥青地面纹理、保留极弱接触阴影。整体低曝光、浓郁黑位、集中高光、冷峻神秘，避免悬浮感。
背景地面铺设低矮、水平流动的自然平流浓雾，雾层贴地延展，局部受到顶部光线照亮，形成柔和的空间纵深与空气透视。雾气不得从轮胎、排气管或车身冒出，禁止烧胎烟雾、稀疏薄雾、烟柱及浓烟。整体冷峻、深沉、真实，强调地面光影、主体雕塑感与电影摄影棚质感，避免死黑地面、地面反光、地面亮度统一、无聚光感、过曝光源、虚假轮廓光及AI渲染感。 
```
