# AI理解的蒙版塑光、塑影，貌似不错……这次，让 AI 模拟了商业修图师的 Dodge & Bur

分类：光影塑形与原片增强。共3组。

[提示词原文](提示词.txt)

```text
 
“模拟资深商业摄影修图师在 Lightroom 与 Photoshop 中，通过多层手工局部蒙版完成高水准 Dodge & Burn 明度雕刻。 
首先分析原图主体、真实光源、受光面、背光面、遮挡关系及前中后景空间结构。严格保留原始时间、天气、光线方向、环境色彩与真实反射，不重新设计照明。 
以主体为视觉明度中心，优先通过大范围、多层次、不同强度的柔和蒙版选择性压暗环境，而非大幅提亮主体。重点加深画面边缘、次要物体、远景、遮挡区域及原生阴影，形成明显但不规则、符合空间与光照逻辑的亮度梯度。 
主体内部进行精细分区塑光，分别处理受光面、结构转折、材质反射与暗面，使形体自然立体。保持主体原有曝光基准，保护高光、反射及亮部细节。暗部深邃但不死黑，保留材质纹理与丰富灰阶。 
所有蒙版高度羽化并自然衔接，避免统一压暗、画面塑造不精细、机械暗角、局部黑斑及生硬明暗边界。禁止凭空添加夕阳、灯光、光束、聚光区域、轮廓光或地面亮斑；禁止改变建筑、人物、车辆、物体形态及原始构图。禁止依赖整体对比度、色温或饱和度变化制造效果。 
最终呈现具有明显手工塑光、塑影力度、真实自然光逻辑、深沉空间层次与视觉有冲击力的高级商业摄影质感成片：主体突出，环境收拢，亮部克制，暗部通透，与专业可察的修图痕迹。”
```
