“不改变构图和环境，将照片去灰同时调整为暖红琥珀复古胶片色调，整体覆盖金红色日落氛围光晕，高光偏暖橙与米金色，阴影沉入深青蓝暗部，降低整体饱和度营造轻微褪色感，增加柔和黄昏光效果，保持原图构图、主体和细节不变，呈现怀旧、温暖、梦幻的复古游乐园氛围，蓝色改青蓝（包括天空），黄色改橘红。”
