# 用AI调出了电影故事感 | 奶油青灰负片 这个提示词尝试了超多次，满意的画面终于显现，奶油光感搭

分类：胶片复古与相机色彩。共3组。

[提示词原文](提示词.txt)

```text
 
留原片构图、人物身份、动作、裁切、透视及所有物体位置，不新增人物、物体、文字、边框、漏光条纹，也不改动任何空间关系。整体做显著的老式彩色负片电影化重调色，非平面滤镜。建立深青黑暗部、灰青绿色环境与奶油暖光的明确分离：蓝色转低饱和暗灰青绿，暗部转暗青灰；原有暖色物体保留自身综合色彩关系，不统一染色。红橙偏向低饱和橙红与琥珀黄，保持自然浓度，不额外增减饱和度。 
亮部以低饱和象牙白、奶油白为主，仅带轻微暖黄，避免变成浓重金黄或橙色。压低非受光中间调，背光面可接近剪影，黑底略带炭灰而非死黑；阴影融合成大块深炭黑青，主体仅保留受光轮廓与必要辨识细节，强化大块明暗关系。 
降低背景中尺度纹理、细节与边缘反差，远景仅保留模糊色块和大轮廓。已有亮区向周围大范围柔和漫射并产生光学雾化，形成克制的低饱和奶油色雾幕、乳状光晕与halation，柔化硬边并适度抬亮背景中间调。奶油黄色只存在于受光扩散、辉光和halation，不覆盖全画面；雾感必须由亮区扩散产生，不得洗灰或侵入前景深青黑、炭黑色块，黑位保持纯净、深沉、完整。 
加入黑柔柔焦与旧镜头扩散感，重点集中于高亮边缘、受光轮廓和亮区过渡；背景可更朦胧，但主体受光结构仍清晰可辨，避免全画面灰、脏、糊。胶片颗粒细密、均匀、低对比，覆盖亮部、中间调和暗部，暗部可见细腻颗粒但不得抬高噪声或破坏黑位；避免粗颗粒、结团、斑驳、数字噪点和扫描灰尘。 
最终保持深青黑、灰青绿、橙红、琥珀黄、象牙奶油色的清晰分离，整体浓郁、暮色、梦幻、平滑、朦胧，具有厚重但干净的老式彩色负片与旧电影质感，强调空气感、胶片漫射光、光学扩散与柔和层次。禁止黄金时刻、蓝调时刻及任何整体黄染。 
```
