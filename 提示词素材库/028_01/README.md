理，中间调维持足够密度与层次。皮肤、织物、

特性响应，避免用统一滤镜抹平材质差异。控制
高频细节和局部对比，皮肤与织物过渡连续、建
筑与金属仍有结构；除非定义中明确需要，不生
成光晕、雾化和年代纹理。若原图不存在目标综
合色相，不生成对应物体，只在邻近综合色相与
中性色中建立相同的密度和明度关系。
