# 冷暗深影

分类：暗调冷色与雾感。共1组。

[提示词原文](提示词.txt)

```text
将照片重新构造成一张深沉、干净、具有视觉密度和材质重量的高级旅行摄影，而不是简单把
曝光压低。保留主体人物身份、五官、姿势、服装、地点真实性、场景主要特征、天气、时间
和原始真实光源，不把白天变成夜晚，不增加乌云、戏剧灯光、霓虹、强轮廓光或不存在的阴
影。清理无关环境与人物。保留能够形成空间深度、地点气质和旅行氛围的真实环境结构。不
依赖背景虚化突出主体，而是通过明暗密度、局部对比、材质、综合色彩和视觉重心让人物自
然融入暗调环境，同时保持第一视觉中心。人物精修保持真实，不单独把脸提亮，不磨皮，不
改变体型，只处理临时瑕疵、碎发、综合色彩不均和杂乱反光。在此基础上建立明显的冷中性
深调体系。整体曝光适度降低，中间调明显下沉，使画面进入低亮度、高综合色密度的状态，
但真正重点是“颜色变深、变厚”
，而不是简单加黑。高光必须保留，作为整个暗调画面的呼
吸点。天空亮部、窗光、灯光、玻璃反射、浅色材质和皮肤受光面保持中性白、冷白或原真实
光源颜色，禁止变成金黄、橙黄或棕黄色。阴影采用深蓝灰、石墨灰、冷灰绿、墨青、灰紫和
近黑中性色。棕色只能存在于原本真实的木材、皮革、土壤等物体中，不能污染综合色阴影。
黑色要深但有层次。黑衣服、头发、道路、树林、建筑阴影等区域保留轻微蓝灰、石墨或冷中
色，使暗部看起来干净、有质感，而不是脏黑或死黑。原有综合色彩降低明度但保留色相：绿
色进入墨绿、深橄榄、冷杉绿；蓝色进入深钢蓝、蓝黑；红色进入酒红或暗砖红；黄色明显降
低存在感，避免暗部发黄发棕。人物肤色同步进入暗调，不单独提亮，但保留中性微暖血色、
面部结构和真实皮肤纹理。禁止橙褐肤色、黄棕阴影和黑金人像效果。增加暗部材质的微反
差，使布料、皮革、石材、木材、植物、玻璃等区域在低亮度中依然具有触感和层次。最终效
果应该呈现：暗、静、深、厚、冷中性、干净、有重量、有高级摄影的密度感，而不是欠曝或
罩了一层棕色滤镜。避免：暗黄、棕色滤镜、复古暖黑、黑金、橙色肤色、黄色阴影、死黑、
强暗角、夜景化、青橙电影 LUT、过度压曝光。
```
