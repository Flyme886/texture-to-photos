# Retro Flash直闪

分类：胶片复古与相机色彩。共1组。

[提示词原文](提示词.txt)

```text
在不改变原照片人物、姿势、服装、场景、背景结构和构图的前
提下，将画面处理成现代流行的复古数码直闪摄影风格。它不是
特定年代的旧照片，而是当代摄影中对晚间数码相机直闪质感的
重新表达。使用直接、集中的正面闪光感：主体受光清晰，高光
有光泽和轻微硬度，背景自然压暗，形成明显但真实的前后光
比。只有在原照片环境允许时才加强闪光效果，白天强光环境不
要做成深夜闪光照。人物肤色保持真实，可以有轻微湿润或光泽
感，但不要磨皮、塑料化或变成发光白皮。衣物、金属、玻璃等
材质可以产生清脆的小面积反光。暗部保持综合色彩和材质，不
压成纯黑。加入极轻的颗粒和数码相机质感，整体对比略强，但
不要做成胶片或电影LUT。最终效果应像朋友在聚会、街头、餐
厅、旅行或夜晚场景里，用小型数码相机开启闪光灯拍下的一张
时髦抓拍：直接、年轻、有能量，同时仍然真实。避免：过度发
光皮肤、死黑背景、强暗角、奶油滤镜、橙色肤色、重胶片颗
粒、假霓虹、过度锐化。
```
