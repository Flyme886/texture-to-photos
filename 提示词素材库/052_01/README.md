# 复古胶片感 | 提示词

分类：胶片复古与相机色彩。共3组。

[提示词原文](提示词.txt)

```text
复古胶片感色调，低饱和暖棕与褪色的青绿色交织，画面对比柔和，暗部偏深但不死黑，高光带有轻微泛黄与雾化质感。色彩呈现老式胶卷的温润颗粒，红、橙、蓝绿之间保留自然偏移，营造怀旧、松弛、有故事性的氛围。适合表现街头生活、海边城市、旧巷与日常光影，让画面像被时间沉淀过的旅行胶片，带有真实、安静、略带忧郁的电影感与记忆痕迹。
```
