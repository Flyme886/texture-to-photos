# 阴天照片别删，试试这个暗金般的提示词

分类：暖光黄昏与秋日。共3组。

[提示词原文](提示词.txt)

```text
保持原图主体、构图、场景、天气、天空、透视和物体
位置不变。重构为低饱和、陈旧烟熏感的旧金褐影调。
暖光只选择性覆盖约15-25%的关键表面，其余大面积
区域迅速沉入低饱和深褐、橄榄黑与烟灰黑；明显压缩
中间调，非关键暗部允许细节、纹理和综合色彩分离自
然消失，并降低暗部清晰度与微反差。受光面以褪色奶
油黄、暗旧金和浅琥珀为主，避免鲜艳橙金；高光略带
陈旧暖白，柔和滚降。综合色彩集中于少量受光区域，
阴影保持浑厚、闷暗、低纯度，形成大块亮暗分区而非
精细HDR层次。保持真实遮挡和材质受光，不改变天气
与昼夜。禁止夕阳化、全局橙黄化、鲜艳金橙、通透
HDR、过强Clarity、遍布主体的轮廓光、暗部过度恢复
及现代商业大片质感。
```
