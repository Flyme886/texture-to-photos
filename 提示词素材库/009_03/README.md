# 暴风雨夜

分类：风格重构与特殊题材。共1组。

[提示词原文](提示词.txt)

```text
严格保持原视频人物、服装、车辆、场景、构图及动作不变。将白天转为深蓝黑色、高反差的风暴傍晚，大面积环境自然沉入深暗，仅保留微弱冷色天光。
猛烈横向阵风裹挟真实暴雨高速掠过镜头。雨滴细小透明，以近水平、低倾角的细短断续拖影为主，长短疏密随机变化，呈不规则阵风雨束。严禁雪花状白点、粗大亮斑、羽毛状雨痕、均匀斜线雨幕。
车灯大灯主动亮起，仅车灯照射范围内的雨滴产生密集冷白亮痕，亮度随距离衰减，其余雨滴隐入暗部。人物车辆自然压暗，衣物湿透，表面少量水珠。地面深暗湿润，仅局部破碎反光，无大面积积水或镜面反射。远景保留空间纵深，无白雾。镜头随强风轻微不规则震颤。整体电影级低调布光，禁止全局补光、灰蒙蒙画面及过度HDR。避免:暖色灯光、AIGC感、冲击力小、地面不合理反光、主体边缘发光、主体抠图感、数码感、无层次、特效感。 
```
