# 复古苔青胶片 | 提示词

分类：胶片复古与相机色彩。共3组。

[提示词原文](提示词.txt)

```text
硬性锁定：完整锁定原图构图、视角、透视、全部物体位置轮廓，不增删移动任何元素，仅调整光影色彩质感；光影：保留原生日光去灰更通透，画面整体明亮通透不压暗，高光保留云层细节、阴影加厚但不死黑，强化胶片明暗反差；色温色调：日光轻微偏暖，形成高光淡金暖调、阴影深苔青蓝绿，中间调带橄榄绿倾向；色彩控制：降低数码饱和度，天空、地面呈现通透深苔青，绿植转为橄榄灰绿，去除荧光色，建筑道路维持灰褐色，中性白色不被染色，不强行篡改物体原生色彩；质感：保留全部实景纹理，不过度锐化，添加细腻轻微胶片颗粒，模拟135胶片直出；氛围：日系乡郊通透晴天纪实，深苔青复古胶片，冷暖平衡，通透厚重，轻微褪色纪实感；负面禁止：改动构图物体、全图泛青、荧光色、橙蓝滤镜、HDR塑料感、死黑、过曝、强暗角、过度锐化、明显人工滤镜效果。
```
