# 画面显平的秋日照，不妨试试这个提示词

分类：暖光黄昏与秋日。共3组。

[提示词原文](提示词.txt)

```text
将原始照片转换为自然、浓郁、沉静、厚重、大胆的电影负片摄影质感
，严格保留原始场景、构图。
采用空间选择性影调重构，而非整体压暗。树林、植被及遮蔽区域呈深
橄榄绿、黑绿色与冷灰棕，黑位深沉稳定，暗部浓郁近黑。人物及真实
受光物体维持自然中间调，形成清晰而柔和的明暗分离。
高光依据原始光照自适应处理：明亮天空呈奶油白、暖灰白，允许轻微
自然溢出；逆光远景具有适度空气散射与柔和透视；重建高亮、柔和、
充满空气散射的光照环境，天空及强受光区域失去原本细节并呈奶油白
与淡暖金色，允许高光自然溢出、柔和扩散，并通过薄雾、空气透视与
光线散射使远景逐渐失去局部对比度。
整体色彩低饱和，以灰棕、烟草棕、深橄榄绿和暗金色为主。暖色仅集
中于真实受光区域，阴影保持冷中性与灰绿色，避免整体泛黄泛橙。
模拟真实胶片的柔和高光过渡、厚重中间调、细腻颗粒与自然色彩密度
。压缩细碎纹理微反差，保留主要轮廓与材质细节。
最终呈现亮部柔和、有明暗层次、暗部深沉、空间通透、冷暖克制的自
然主义电影氛围。避免灰雾、过度柔焦、明显光束、金色泛光、HDR及
统一曝光处理。
```
