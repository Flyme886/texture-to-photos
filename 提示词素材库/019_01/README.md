# 墨青下的潮湿感，仅剩光与轮廓，脱离现实

分类：暗调冷色与雾感。共3组。

[提示词原文](提示词.txt)

```text
 
严格保留输入照片的人物数量、位置、比例、姿态、动作和整体构图，不改变人物形体，不添加新的场景元素。
背景中不得存在任何可识别环境。原始树木、山、水、道路、建筑、地平线及其他景物完全失去形状和身份；背景只表现为极低频、极平滑、无断层、无对象的大尺度综合色彩与明度场，不生成浓雾、云团、烟、光束或幻想背景。
背景综合色彩限制为浅 cyan、cyan-green、teal、deep teal、墨绿和青黑。综合色彩之间柔和、连续、无结块，并建立明确但宽缓的纵向明度下沉：上部较亮，中部进入饱和 teal 与青绿，中下部进入 deep teal 与墨绿，图片下方三分之一沉入深墨绿—青黑。过渡必须柔软、连续，没有机械渐变线，也不能形成纯黑遮罩。
人物整体压成深青黑—墨绿黑的近剪影。脸部完全不可辨认，只保留头部整体形状和朝向；服装图案、条纹、褶皱和材质大幅消失，人物主要成为连续的深青黑综合色块。
人物实体感沿身体向下逐渐减弱：头肩轮廓相对明确，躯干逐渐降低与背景的明度差；腰部以下越来越接近周围 deep teal / 墨绿暗场，人物下端自然与下方融合。不要透明渐变，不要烟化，不要粒子消散，不要数字 dissolve。
人物做近乎纯黑剪影融入环境，轮廓采用低解析摄影式柔边。头发和原本可飘动的边缘只允许极轻微的单方向短拖曳，形成自然风感，不制造整个人的运动拖尾。
整体降低数字锐度、局部微反差和空间解析力，使画面保持柔软、连续、低频的摄影质感。
颗粒必须明显但干净。使用细中等尺度、随机、少量明显的银盐颗粒，主要存在于暗部与中暗部，亮部更细更轻。但不要形成明显聚团、脏块、污点、霉斑、砂纸感或乳剂损伤感。暗部应有银盐质感，但仍保持干净、通透和连续，不要让颗粒破坏综合色彩过渡。
无重度旧照片损伤。不要大量尘点、脏污、污渍、纸张纹理、胶片烧伤、霉点、颗粒结团或局部发灰。最多只允许极少量几乎不抢眼的漏光与划痕。
最终画面应呈现：光源侧较亮、反光源侧中下部明显沉暗；整体必须潮湿。 
```
