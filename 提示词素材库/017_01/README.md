# AI原片增强，不喜调色，喜原色的速藏

分类：光影塑形与原片增强。共3组。

[提示词原文](提示词.txt)

```text
 
将这张图片优超写实的 8K、专业 DSLR 级照片，同时保持主体身份、场景结构和原始观感自然真实。必要时按照专业摄影原则自动优化取景与构图。建立清晰的视觉主次关系，让主体成为画面最强的视觉焦点，次要元素只起陪衬作用，不抢主体。通过景深、对比度、光线和明暗关系，让主体与背景形成自然分离。 
建立专业、清晰的明暗结构：在符合场景逻辑的前提下，让主体相对周围环境略亮或更突出，同时保留真实的高光与阴影细节，避免画面发平。利用轻微的局部对比和明暗差，引导视线自然集中到主体。保证明暗过渡平滑、动态范围均衡、物体有立体感，并保留真实自然的光线衰减。 
加入真实高级的背景虚化、柔和顺滑的奶油散景和自然景深。根据场景智能优化光线，加入电影感柔光、真实阴影、自然肤色、轻微光晕以及符合场景逻辑的方向性光线。提升清晰度、纹理、色彩、微对比和细节，但整体仍保持真实、高级，像昂贵 DSLR 或旗舰 iPhone 实拍。 
保留自然比例、真实材质、真实色彩和原有氛围。避免过度修图、加云层、加太阳、发灰、发黄、过度锐化、假 HDR、死黑阴影、过曝高光、塑料皮肤、过饱和、假光源、边缘光晕以及明显的 AI 感。 
```
