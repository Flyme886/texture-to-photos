分类：青橙冷暖电影色。共3组。

[提示词原文](提示词.txt)

```text
 
保持原图主体、构图、透视、物体数量、建筑结构和关键场景关系不变，只重构色彩、明暗、光影与成像质感。整体压低中间调和环境补光，建立高亮青白天空、少量砂金/琥珀受光面与大面积深青黑背光面的强反差关系。天空向浅青白、淡青灰白整理，允许接近高白点甚至轻微过曝，但保持平滑干净。建筑背光、檐下、玻璃内侧、道路阴影和非关键区域明显压暗，进入深青灰、蓝黑、青黑与综合色彩黑，不平均提亮暗部。真实受光的道路、墙面、建筑边缘、道路标线、招牌及少量人物受光面集中呈砂金、旧金黄、琥珀黄和暖灰褐，暖色只服从真实受光关系，不整体加黄，也不凭空制造夕阳或额外光源。玻璃、金属与反射表面依据朝向独立处理，保留冷青灰或中性反射，背光侧保持深冷与低亮；深色建筑保持重量。人物存在时保护自然肤色与真实体积，不让冷青或暖黄污染肤色。整体减少中间调，黑位深、白点高、局部暖色密度高，形成高亮冷青白、深青黑与少量暖金三者明确分区的低曝光城市硬光质感；禁止 HDR、禁止整体提亮、禁止把天空做成正常高饱和蓝天。 
```
