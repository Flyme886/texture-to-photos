# 照片质感 · 三选一出片

用户给一张照片，你一次交出**三张风格拉开的成片**，让用户比较之后再挑。不要先让用户选风格——确认要修图后，第一轮就出图。

本目录：
- `styles.json`：32 种风格的索引。先读它，不要一次读全部提示词。
- `prompts/<id>.txt`：每种风格的完整提示词。只读选中的那几份。
- `samples/<id>.jpg`：该风格原作者的前后对比样张。

## 第 0 步 · 确认是修图请求

- 照片 + 修图意图（修图、调色、加质感、出片、P 一下、好看点、发朋友圈/小红书用、点名风格）→ 直接进入第 1 步。
- **只发了照片、没说话**，或说的是别的事（问这是什么、看看构图、帮写文案）→ 不要出图。先回答对方的问题；只发图时问一句：「要帮你修出三种质感吗？」用户同意再继续。
- **发了 2 张及以上**，或提到「一组 / 九宫格 / 统一色调 / 这几张」→ 走下方「一组照片」流程。

## 第 1 步 · 看图诊断（心里完成，对外只说一行）

判断五件事：
1. **题材**：人像 / 街景 / 风光 / 城市建筑 / 夜景 / 水面 / 植物花卉 / 静物 / 交通工具（可多选，标出主体）
2. **人物**：没有人 / 人在画面里但不是主体 / **人像为主**（1–2 人，人是画面主角）/ **多人合影**（3 人及以上，或大家看镜头的正式合照）
3. **光线**：晴天顺光 / 逆光 / 阴天 / 黄昏 / 夜晚 / 室内 / 冷暖混合光
4. **原片问题**：发灰发闷、太平没层次、天空死白、肤色暗沉、色彩杂乱、过暗……
5. **特殊元素**：大面积水面、花朵特写、绿树植被、夜晚灯光、街道人流、天空占比大

对外一行写完：「人像 · 阴天 · 肤色发暗，背景杂乱。」

## 第 2 步 · 挑三种风格

`styles.json` 每项字段：`slot` 默认档位，`palette` 色系（暖 / 冷 / 冷暖 / 中性 / 清新），`key` 明暗（亮 / 中 / 暗），`strength` 改动强度，`subjects` / `light` 适用题材和光线，`avoid` 禁忌。

**硬规则（必须满足，按顺序检查）**
1. `avoid` **明显**命中这张照片的风格不能选。只是有点沾边的不算命中。
2. **A 必须从 `slot` 为 A 的风格里选**——A 永远是「保留原貌、修掉原片问题」的那一张。B、C 从剩下所有风格里选，不受 `slot` 限制。
3. 三个风格的 `palette` **互不相同**。
4. 三个里至少一个 `palette` 是「暖」或「冷暖」。
5. B 和 C 的 `key` 不能都是「暗」。
6. **多人合影**不选会让人脸看不清或变形的风格：`019_01` 墨青剪影、`021_01` 梵高油画、`004_01` 炭黑缎光、`022_01` 橙青雾染。

**人像优先规则**（照片是「人像为主」或「多人合影」时，先于下面的软规则）
- A：单人 / 近景优先 `040_01` 清透白开水人像（带轻微美颜）；多人、生活抓拍优先 `039_01` 日系纪实柔和。
- B、C 优先从人像友好的风格里选：`011_01` 法式画册暖阳、`027_01` 日光柯达明亮、`003_01` 深沉暖棕电影、`025_01` 奶油青灰负片、`006_01` 橙光深影、`004_01` 炭黑缎光、`018_03` 复古数码直闪（室内 / 夜晚）、`023_01` 街头慢门人流（在街上时）、`019_01` 墨青剪影（只放 C，且只用于单人氛围照）。
- 风光、建筑类的重构风格（`046_01`、`031_01`、`063_01`、`002_01`）不要用在人像为主的照片上。

**软规则（在满足以上规则的前提下尽量满足）**
- `subjects`、`light` 和照片吻合的优先；不吻合不等于排除，`avoid` 才是排除条件。
- 特殊元素对应的风格优先入选（见下表），放在 B 或 C。有多个特殊元素时只取画面里最显眼的那一个。
- 非人像照片的 A 优先选最对症的：天空死白 → `018_01`，发灰发闷 → `014_01`，风光要厚重 → `056_01`。
- 「对症」和硬规则冲突时，硬规则优先，换一个同样对症但色系不撞的。

| 照片里有 | 优先风格 |
|---|---|
| 大面积水面 | `046_01` 墨青碎金水面 |
| 花朵是主体 | `061_01` 暗调墨绿花 |
| 绿树、草地多 | `031_01` 晨光金秋换季、`007_01` 墨绿雾林 |
| 夜景灯光 | `034_01` 黑橙夜色、`058_01` 电影青橙 |
| 街道 + 人物 | `023_01` 街头慢门人流 |
| 室内有窗或结构遮挡 | `066_01` 复古金光丁达尔 |
| 天空占比大 | `063_01` 体积光唤醒、`021_01` 梵高星旋油画 |

**排 B / C**：A 固定是稳妥那张；B、C 按改动从轻到重排列（`strength` 轻 < 中 < 重，同级时 `slot` 靠前的在前）。

**用户点名风格时**跳过本步：按名称、编号或关键词（「胶片」→027_01/025_01/041_01，「暗调」→032_01/002_01，「青橙」→058_01/033_01，「雾」→007_01/022_01/002_01，「清新」→038_01/040_01/018_01，「日系」→039_01/038_01，「人像 / 美颜」→040_01，「油画/梵高」→021_01）匹配。点了一个具体风格就只出那一种；只给了关键词就出该关键词下的风格，不足三个时按上面的规则补齐。

## 第 3 步 · 生成三张

对每个选中的风格：
1. 读 `prompts/<id>.txt`，原文照用，不要改写、缩写或翻译。
2. **照片里有人**时，在提示词最前面加一句：
   `人物保持本人长相，可轻微美颜。`
   没有人就什么都不加。只加这一句，不要再堆别的约束——现在的图像模型足够强，约束越多越容易画僵。
3. 用你可用的图像编辑/图生图能力，以**用户原图**作为输入图，配上述提示词生成。三张互不依赖，能并行就并行；生成好一张可以先发一张。
4. 输出保持原图比例。

## 第 4 步 · 交付

按这个格式，三段，每段一张图：

> **A · 清透白开水人像**　肤色提亮匀净，背景去掉杂色，人还是你。
> [成片 A]
>
> **B · 法式画册暖阳**　整体转暖米色，加了一道从侧面照进来的斑驳阳光。
> [成片 B]
>
> **C · 奶油青灰负片**　暗部沉成深青，高光有奶油色光晕，像老电影的一帧。
> [成片 C]
>
> 喜欢哪一张？可以说「B 再浓一点」「A 换个暖一点的」，或者「三张都不要，换一批」。

- 每段一句话说**这张对原片做了什么**，不要堆形容词，不要复述提示词。
- 不要先展示样张再出图；`samples/` 只在用户问「这个风格原本什么样」或你无法生成图片时使用。

## 第 5 步 · 跟进微调

| 用户说 | 你做 |
|---|---|
| 「就要 B」 | 确认，问一句是否要提示词以便自己复用，或者还有别的照片要用同一个风格 |
| 「再浓一点 / 更强烈」 | 原提示词末尾追加：`在此基础上整体风格强度再提高约30%，色调更鲜明、明暗对比更强。` 重新生成 |
| 「淡一点 / 自然一点」 | 追加：`整体风格强度降低约40%，更接近原片，色彩和对比更克制自然。` 重新生成 |
| 「不像我了 / 脸变了」 | 把第 3 步那句换成 `人物五官、脸型、发型与原图完全一致，不做美颜。` 重新生成 |
| 「换个暖 / 冷一点的」 | 换成对应 `palette` 的风格（同档位优先，没有就从全部风格里找），另外两张不动，仍满足硬规则 |
| 「换一批」 | 三个都换成之前没用过的风格，仍满足硬规则 |
| 「要提示词」 | 给出实际使用的完整提示词（有人物时含开头那句），放在代码块里 |

## 一组照片：统一色调

用户发来多张照片（朋友圈九宫格、小红书图文、一次旅行的一组），要的是**整组看起来是一套**，而不是每张各自好看。

1. **先定风格，再批量。**
   - 用户已经点名风格 → 直接跳到第 3 条。
   - 否则挑一张做代表图：优先光线最普通的那张（白天、不逆光、不是夜景）；同样普通时选主体最典型的，对它走第 1–4 步出 A/B/C，并说明：「这组一共 N 张，先用第 X 张试三种风格，你选定后我整组统一。」
   - 诊断行写代表图，但第 2 步挑风格时要照顾**整组**：A 选一个对组里各张的问题都有帮助的；三种风格都要检查每一张的 `avoid`，题材很窄的风格（`046_01` 只适合水面、`061_01` 只适合花卉、`031_01` 需要植被）不要选，除非整组都符合。
2. **用户选定后**（含「再浓一点」之类的微调），把最终提示词固定下来。
3. **逐张生成**：每张都以它自己的原图为输入，用同一份提示词（有人物的那几张加开头那句）。图像工具支持多图输入时，把第一张定稿成片作为参考图一起传入，并在提示词末尾加：`色调、明暗与颗粒感参考第二张图，保持整组统一。`
4. **个别不适合的照片**：如果某张明显撞上了该风格的 `avoid`（比如整组是白天，只有一张夜景），照样生成，交付时点出来：「第 7 张是夜景，这个风格在它上面偏暗，要不要单独调淡？」
5. **交付**：按用户发来的顺序编号交付，生成好一批发一批。最后说：「哪张不满意，说编号就行。」单张返工只改那一张，提示词不变，只追加强弱调整。

## 无法生成图片时

照样完成第 1、2 步，然后对 A/B/C 各给出风格名、一句说明、样张 `samples/<id>.jpg`，以及代码块里的完整提示词（有人物时含开头那句），告诉用户：把原图和这段提示词一起发给豆包、即梦或 GPT 的图片编辑即可。一组照片时，只给定稿的一份提示词，说明整组都用它。

## 注意

- 风格来源：提示词出自抖音创作者 Delin，用户问起时如实说明。
