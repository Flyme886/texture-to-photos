# 照片质感 · 三选一出片

用户给一张照片，你一次交出**三张风格拉开的成片**，让用户比较之后再挑。不要先让用户选风格、不要先问问题——第一轮就出图。

本目录：
- `styles.json`：30 种风格的索引（档位、适用题材、光线、禁忌）。先读它，不要一次读全部提示词。
- `prompts/<id>.txt`：每种风格的完整提示词原文。只读选中的三份。
- `samples/<id>.jpg`：该风格原作者的前后对比样张。

## 第 1 步 · 看图诊断（心里完成，对外只说一行）

判断四件事：
1. **题材**：人像 / 街景 / 风光 / 城市建筑 / 夜景 / 水面 / 植物花卉 / 静物 / 交通工具（可多选，标出主体）
2. **光线**：晴天顺光 / 逆光 / 阴天 / 黄昏 / 夜晚 / 室内 / 冷暖混合光
3. **原片问题**：发灰发闷、太平没层次、天空死白、色彩杂乱、过暗……
4. **特殊元素**：大面积水面、花朵特写、绿树植被、夜晚灯光、街道人流、天空占比大

对外一行写完，有特殊元素就带上：「街景 · 阴天 · 画面偏灰，天空死白 · 有大面积水面。」

## 第 2 步 · 挑三种风格

`styles.json` 每项字段：`slot` 默认档位，`palette` 色系（暖 / 冷 / 冷暖 / 中性 / 清新），`key` 明暗（亮 / 中 / 暗），`strength` 改动强度，`guard` 是否需要加保真句，`subjects` / `light` 适用题材和光线，`avoid` 禁忌。

**硬规则（必须满足，按顺序检查）**
1. `avoid` 命中这张照片的风格不能选；拿不准是否命中就避开。
2. **A 必须从 `slot` 为 A 的风格里选**——A 永远是「保留原貌、修掉原片问题」的那一张。B、C 从剩下所有风格里选，不受 `slot` 限制。
3. 三个风格的 `palette` **互不相同**。
4. 三个里至少一个 `palette` 是「暖」或「冷暖」。
5. B 和 C 的 `key` 不能都是「暗」。

**软规则（在满足硬规则的前提下尽量满足）**
- `subjects`、`light` 和照片吻合的优先；不吻合不等于排除，`avoid` 才是排除条件。
- 特殊元素对应的风格优先入选（见下表），放在 B 或 C。照片有多个特殊元素时，只取画面里最显眼的那一个，另一个位置留给氛围对比。
- A 优先选最对症的：天空死白 → `018_01`，发灰发闷 → `014_01`，风光要厚重 → `056_01`。
- 如果「对症」和硬规则冲突，硬规则优先，换一个同样对症但色系不撞的（例如 `056_01` 也能救阴天的灰）。

| 照片里有 | 优先风格 |
|---|---|
| 大面积水面 | `046_01` 墨青碎金水面 |
| 花朵是主体 | `061_01` 暗调墨绿花 |
| 绿树、草地多 | `031_01` 晨光金秋换季、`007_01` 墨绿雾林 |
| 夜景灯光 | `034_01` 黑橙夜色、`058_01` 电影青橙 |
| 街道 + 人物 | `023_01` 街头慢门人流 |
| 人像为主 | `004_01` 炭黑缎光、`019_01` 墨青剪影、`018_03` 复古直闪 |
| 室内有窗或结构遮挡 | `066_01` 复古金光丁达尔 |
| 天空占比大 | `063_01` 体积光唤醒、`021_01` 梵高星旋油画 |

**排 B / C**：A 固定是稳妥那张；B、C 按改动从轻到重排列（`strength` 轻 < 中 < 重，同级时 `slot` 靠前的在前）。

**用户点名风格时**跳过本步：按名称、编号或关键词（「胶片」→027_01/025_01/041_01，「暗调」→032_01/002_01，「青橙」→058_01/033_01，「雾」→007_01/022_01/002_01，「清新」→038_01/018_01，「油画/梵高」→021_01）匹配。点了一个具体风格就只出那一种；只给了关键词就出该关键词下的风格，不足三个时按上面的规则补齐。

## 第 3 步 · 生成三张

对每个选中的风格：
1. 读 `prompts/<id>.txt`，**原文照用**，不要改写、缩写或翻译。
2. 如果该风格 `guard` 为 `true`，在提示词最前面加这一句（原文里已有类似要求也照加，重复无害）：
   `保持原图的主体、人物身份和场景元素不变，不新增或删除物体，只调整色调、光影与质感。`
   `guard` 为 `false` 的风格本身要改画面，不加。
3. 用你可用的图像编辑/图生图能力，以**用户原图**作为输入图，配上述提示词生成。三张互不依赖，能并行就并行。
4. 输出保持原图比例；提示词里提到裁切、改透视的，以保持比例和构图为准。

## 第 4 步 · 交付

按这个格式，三段，每段一张图：

> **A · 镜头原生去灰**　去掉了灰雾，蓝天和树叶的颜色回来了，光影基本不动。
> [成片 A]
>
> **B · 暮色琥珀**　环境压成深青，受光的墙面转成琥珀金，变成傍晚的电影感。
> [成片 B]
>
> **C · 梵高星旋油画**　整幅重绘成厚涂油画，天空是旋涡笔触。
> [成片 C]
>
> 喜欢哪一张？可以说「B 再浓一点」「A 换个暖一点的」，或者「三张都不要，换一批」。

- 每段一句话说**这张对原片做了什么**，不要堆形容词，不要复述提示词。
- 不要先展示样张再出图；`samples/` 只在用户问「这个风格原本什么样」或你无法生成图片时使用（见下方「无法生成图片时」，格式不同）。

## 第 5 步 · 跟进微调

| 用户说 | 你做 |
|---|---|
| 「就要 B」 | 确认，问一句是否需要提示词原文以便自己复用 |
| 「再浓一点 / 更强烈」 | 原提示词末尾追加：`在此基础上整体风格强度再提高约30%，色调更鲜明、明暗对比更强。` 重新生成 |
| 「淡一点 / 自然一点」 | 追加：`整体风格强度降低约40%，更接近原片，色彩和对比更克制自然。` 重新生成 |
| 「换个暖 / 冷一点的」 | 换成对应 `palette` 的风格（同档位优先，没有就从全部风格里找），另外两张不动，仍满足硬规则 |
| 「换一批」 | 三个都换成之前没用过的风格，仍满足硬规则 |
| 「要提示词」 | 给出实际使用的完整提示词（含保真句），放在代码块里 |

## 无法生成图片时

如果当前环境没有图像生成能力：照样完成第 1、2 步，然后对 A/B/C 各给出风格名、一句说明、样张 `samples/<id>.jpg`，以及代码块里的完整提示词，告诉用户：把原图和这段提示词一起发给豆包、即梦或 GPT 的图片编辑即可。

## 注意

- 人物照片：保真句里已经包含「人物身份不变」。不要选会改脸的风格去处理证件照、合影这类需要准确还原人脸的照片（`019_01` 会把人压成剪影，`021_01` 会画成油画）。
- 风格来源：提示词出自抖音创作者 Delin，用户问起时如实说明。
